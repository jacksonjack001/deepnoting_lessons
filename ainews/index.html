💧 Claude 文字水印全球上线

采用 Google DeepMind SynthID-Text（2024 Nature 论文版本）。
机制：候选词被分成 “绿名单”+“红名单”，密钥 + 前文 n-gram 决定选词；整篇 >50% 绿名单词即判定为 AI 生成。
OpenAI 内部调查：30% 用户威胁转投对手，所以没发；xAI 根本没签欧盟 AI 法案。

📣 用户反弹

翻译 / 润色 / 改错别字都会被带上水印 —— "因用铅笔写字而要求把铅笔列为作者"。

Takeaways

🎯 本周 5 大观察

  1. 模型能力的“真边界”藏在内部报告里
    Anthropic Model 2 / OpenAI Astra —— 前沿能力不再发布给消费者，“风险报告 + 红队测试”成为新常态。
  2. Agent Harness 是下一个战场
    DeepSeek Harness / OpenAI Codex Harness / Anthropic Claude Code / Cursor Origin —— 产品竞争从“模型”转向“执行系统”。
  3. 小激活 + 大验证 = 新范式
    Qwen3.8-27B 单卡跑 Opus 级 —— MoE + 可验证 RL 是性价比杀手。
  4. AI 安全从口号走向“工程红线”
    OpenAI 暂停 RL / Claude 水印反弹 / Claude Code 被红队 RCE —— 安全不再是 PR，而是工程基础设施。
  5. 智能体从“数字”走向“物理世界”
    Fable 5 自主科研 / DeepSeek Creator 模式 / 机器人“银河星脑”端到端 —— 自进化元年从屏幕延伸到现实世界。
